# سياسة النماذج والتكلفة (OpenRouter)

Hermes يطبّق هذا الجدول تلقائياً. المستخدم **لا يختار** النموذج إلا إذا طلب صراحة.

## المستويات

| المستوى | النموذج | متى |
|---------|---------|-----|
| **L0** | DeepSeek **Flash** | تصنيف الطلب، أسئلة قصيرة، checklists، captions مسودة، meta SEO قصير |
| **L1** | DeepSeek **Pro** | outlines، جداول منافسين، هيكل LP، variants إعلان (مسودة)، JSON منظم |
| **L2** | **Claude** | نص **نهائي** AR/EN: LP، مقال، إعلان، رسالة عميل، propuesta |
| **L3** | **Kimi** | PDF/RFP ضخم، ملفات كثيرة، أو سياق > ~50k حرف — ثم L0/L2 للملخص |

## قواعد توفير

1. ابدأ دائماً بـ **L0** إن كانت الإجابة < ~400 كلمة.
2. **Claude** فقط عند: «النسخة النهائية»، نشر، أو عربي B2B حساس.
3. **Kimi** مرة واحدة per مهمة — لا سلسلة Kimi متتابعة.
4. **البرمجة:** Cursor (Software) — لا Claude/HTML طويل على OpenRouter.
5. **الصور AI:** غير افتراضية — أصول `assets/projects/` أولاً.
6. **الفيديو AI:** غير افتراضي — clips المشاريع + CapCut.

## سقف OpenRouter

- هدف: **~20–25 USD/شهر** ضمن إجمالي 40–50 USD.
- تنبيه عند 80% من السقف في لوحة OpenRouter.
- شهر مزدحم (LP + حملة): قلّل Claude إلى «نهائي فقط» وزِد Flash/Pro.

## GPT (اختياري)

إن كان مفعّلاً على OpenRouter: hooks إبداعية فقط (L1)، ثم Claude يصوغ النهائي. يمكن تعطيله لتوفير الميزانية.
