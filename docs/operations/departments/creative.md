# Creative

## المسؤولية

الاتجاه **البصري** والعروض — **ليس** bulk AI images/video.

## مهام نموذجية

- storyboard فيdeo قصير (سوشيال)
- script VO / on-screen text
- هيكل pitch deck / sales gallery narrative
- brief للمصمم (أو للمستخدم) — colors, refs, shots list
- اختيار **أصول موجودة** من مشاريع GH

## المدخلات

- Marketing message house
- `assets/projects/maquettes/`, videos في `assets/videos/`

## المخرجات

- shot list + script
- deck outline (slides titles + notes)
- «استخدم هذا clip / هذه الصورة» — مسارات assets

## النماذج

- Flash — ideas, shot list
- Pro — storyboard structured
- Claude — script AR/EN نهائي، deck narrative

## أدوات الإنتاج (خارج OpenRouter)

- **CapCut / Premiere** — montage
- **Canva** — frames بسيطة
- **لا** Ideogram/Higgsfield كخط افتراضي
