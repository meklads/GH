# Graphics House — تنظيم الأدوات والأقسام

> **الهدف:** قناة واحدة (Hermes) + تنفيذ مواقع (Cursor) + نماذج (OpenRouter).  
> **الميزانية المستهدفة:** ~40–50 USD/شهر (Cursor + OpenRouter).

## الأدوات الثابتة

| الأداة | الدور |
|--------|--------|
| **Hermes** | واجهتك — تصنيف المهام، توزيع الأقسام، اختيار النموذج، تجميع المخرجات |
| **Cursor** | قسم **Software** — موقع، LP، GitHub، Workers، build |
| **OpenRouter** | Claude، Kimi، DeepSeek (Flash / Pro) — عبر Hermes فقط |

**لا نعتمد على:** اشتراك Claude منفصل، Ideogram، Higgsfield (التسويق البصري = أصول مشاريع GH + CapCut).
